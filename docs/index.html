Reloaded Labs #01 · Store Intake & Circular Upcycling Workflow

Guided mobile photo capture & 0–100 intake triage for motorcycle jackets and pants.

Built for Moto Reloaded's store buy-in counter. Scan a desktop QR code from any phone over HTTPS to capture six required garment angles, verify framing locally with frozen pretrained OpenCLIP, and produce a deterministic 0–100 photo coverage + damage disclosure score that routes compromised gear away from buy-in and toward circular upcycling and responsible retirement.

Launch Live App (HTTPS) → Check API Health

Note: The container scales to zero when idle ($0 idle cost on Azure Container Apps) — the first request may take ~10–15 seconds to wake. Public visitors run real Stage-1 OpenCLIP angle verification & Demo Mode scoring at $0 API spend; live Azure OpenAI vision unlocks via passcode.

STAGE 01 · LOCAL VISION

Frozen OpenCLIP Angle Check

Pretrained ViT-B-32 (laion2b_s34b_b79k) runs on CPU in frozen inference mode (model.eval(), torch.no_grad()) to confirm each captured slot (front, left, right, back, inside, labels) with zero training or fine-tuning.

STAGE 02 · RUBRIC AUDIT

Swappable Vision Rubric Boundary

An isolated score_photos() provider invokes zero-training Azure OpenAI (gpt-4.1-mini / gpt-4.1) or Portfolio Demo Mode to return structured pass/fail checklist JSON with observed reasons and full prompt/response observability.

STAGE 03 · DETERMINISTIC SCORE

0–100 Score & Hard Compliance Gate

Pure Python scores photo coverage (0–50) + damage disclosure (0–50). Declared/evident crashes, contamination, or Zone 1 breaches/repairs are hard-capped ≤ 49, declined for buy-in, and routed to circular upcycling & new-gear trade-in.

Cloud Architecture & Credit-Protected Deployment

Single container on Azure Container Apps (1 vCPU / 2 GiB, scale-to-zero, CPU-only PyTorch, pre-baked OpenCLIP cache, ephemeral SQLite + upload cleanup, passcode + hourly/daily live-API rate caps) built via GitHub Actions & GHCR.

FastAPI + Uvicorn OpenCLIP ViT-B-32 (CPU) Azure OpenAI gpt-4.1-mini SQLite Docker (Non-Root) Azure Container Apps GitHub Actions + GHCR 28-Column .xlsx Export
